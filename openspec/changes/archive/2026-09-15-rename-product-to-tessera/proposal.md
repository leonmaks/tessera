## Why

The implementation is named Tessera and its internal identifiers need to consistently reflect that product identity.

## What Changes

- Rename internal package scopes, application metadata, aliases, candidate labels, and Tessera-owned documentation to Tessera.
- Preserve references and links to the upstream application and source repository.

## Capabilities

### New Capabilities
- None.

### Modified Capabilities
- None.

## Impact

This is a non-behavioral branding migration. It changes workspace package identifiers and TypeScript aliases, with no schema or data migration.
